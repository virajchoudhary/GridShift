# Data attribution and permitted claims

GridShift uses the official Great Britain Carbon Intensity API provided by National Energy System Operator.

Source API: https://api.carbonintensity.org.uk/

API definitions: https://carbon-intensity.github.io/api-definitions/

API terms: https://github.com/carbon-intensity/terms

Licence: Creative Commons Attribution 4.0 International, as linked by the API terms.

The separate NESO portal licence applies to portal data. GridShift does not silently combine that archive with its API target.

The numerical target is NESO estimated actual carbon intensity in gCO2/kWh. It represents estimated generation-related operational CO2. It does not establish a full lifecycle CO2e inventory or directly measured GPU emissions.

NESO does not endorse GridShift. No NESO logo or implied certification is used.

The frozen manifest records retrieval dates, URLs, and source hashes. Retrospective values may differ from what a historical user first received. Provider historical forecasts lack verified issue vintages and do not enter scored model comparisons.
